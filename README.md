# ModFinder

Статичний сайт-каталог модів Minecraft на базі публічного API Modrinth.

## Запуск локально
1. Розпакуй архів.
2. Відкрий папку в редакторі коду.
3. Запусти локальний сервер, наприклад розширенням Live Server у VS Code.
   Також можна використати `python -m http.server 8000` і відкрити `http://localhost:8000`.

## Публікація через GitHub + Vercel
1. Створи новий GitHub-репозиторій і завантаж файли з цієї папки.
2. У Vercel натисни Add New → Project та імпортуй репозиторій.
3. Для цього статичного сайту не потрібні Build Command і Output Directory — Vercel може розмістити `index.html` напряму. Якщо запропонує framework, вибери Other.
4. Натисни Deploy.

## Джерело даних
Використовується публічний API Modrinth: https://docs.modrinth.com/api/
ModFinder — незалежний фанатський каталог, не пов'язаний офіційно з Modrinth або Mojang.

## Примітка
Сайт завантажує актуальні дані з Modrinth у браузері, тому для пошуку потрібне підключення до інтернету. Обране зберігається локально в браузері.
